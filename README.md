# OpenMall
교육용 오픈소스 쇼핑몰

> 이 저장소는 [**비주얼 코딩 — 다이어그램으로 시작하는 AI 시대의 프로그래밍**](https://openshelf.cloud/book/visual-coding) 강의에서 사용하는 예제 프로젝트입니다.

## 비주얼 코딩 소개

[비주얼 코딩](https://openshelf.cloud/book/visual-coding)은 **다이어그램을 새로운 프로그래밍 언어로 삼고, 인공지능을 컴파일러처럼 활용하는 개발 방법**을 처음부터 끝까지 안내하는 책이자 강의입니다. 낯선 코드나 서비스를 다이어그램으로 옮겨 이해하는 "읽기"에서 시작해, 직접 다이어그램을 그리고 그것으로 AI와 함께 실제 프로젝트를 만드는 "쓰기"로 나아갑니다.

| 구성 | 내용 |
|---|---|
| 1부. 다이어그램 읽기 | 바둑 게임 사이트·실시간 강의 플랫폼을 코드 없이 다이어그램만으로 이해하기 |
| 2부. 아키텍처 패턴으로 개발 | 파이프라인, 오케스트레이터·워커, 이벤트 드리븐, 마이크로서비스, 레이어드, 상태 기계, 클린·헥사고날·DDD |
| 3부. 패턴을 넘어서 | 조각 간 조정(coordination), Method-R 분해, Spike로 불확실성 먼저 걷어내기 |
| 4~5부. 코드 분석 | play361(바둑)·7pan(화상회의)을 Job Flow·Navigation·State·Screen Layout 다이어그램으로 파고들기 |
| 6부. 다이어그램 그리기 | Navigation·State·Job Flow 다이어그램을 직접 그리기 |
| 7부. 잘 알려진 프로젝트 시작하기 | **OpenMall** 쇼핑몰을 Navigation 다이어그램과 백엔드 없는 가상 사이트로 시작하기 |

이 저장소는 7부의 실습 대상입니다. 강의 본문에 실린 쇼핑몰 화면 이동 다이어그램은 [`docs/navigation.md`](docs/navigation.md)에 그대로 담겨 있습니다.

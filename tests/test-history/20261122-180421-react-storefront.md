# 20261122-180421 · React 생활 편집숍

대상은 [react-storefront](../../prototypes/react-storefront/README.md)다. [기존 설계 검증](2026-11-22-design.md)의 회원 쿠폰 예시와 출고·취소 순서를 참고했다. 이번 기록은 실제 React 화면에서 새로 실행한 결과다.

| 실행 | 관찰 및 판정 |
| --- | --- |
| B1 · 최초 빌드 | Vite가 정적 HTML·JS·CSS 및 WebP를 dist에 생성했다. |
| C1 · Chrome 탐색 | 찜한 상품 클릭 직후 검증 코드가 이전 목록의 상품 3개를 읽어 중단됐다. 경로의 제목이 나타난 뒤 목록을 판정하도록 검증 순서를 고쳤다. |
| C2 · 구매자와 운영자 | 검색 결과 없음과 복귀, 필터, 찜, 수량 변경, 새로고침, 쿠폰 적용을 조작했다. 타월 2개 24,000원과 일반 배송비 3,000원에서 2,000원을 할인해 25,000원을 결제했다. 취소 확인에서 돌아간 뒤 다시 접수하고 환불하자 재고가 18개로 복원됐다. 비회원 바로 구매, 송장 등록, 배송완료, 주문번호·연락처 조회, 반품 환불도 완료했다. |
| V1 · 분리된 시각 검토 | 1280px 홈, 390px 홈·입력된 주문서·주문 상세를 캡처했다. 모바일 상단에서 장바구니 아이콘이 한 줄을 단독으로 차지하고 컬렉션 제목이 어절 중간에서 끊겼다. 모바일 헤더를 그리드로 정렬하고 제목 영역 너비와 줄바꿈을 조정했다. |
| B2 / C3 · 최종 빌드와 재검증 | 빌드 성공. C2의 구매·환불·조회 흐름을 다시 실행했다. 운영 도구의 초기화 취소·승인을 확인했고 새로고침 후 주문이 0건이었다. 390px 홈에서 가로 넘침이 없고 계정과 장바구니가 같은 줄에 보인다. 실행 중 외부 호스트 HTTP 요청과 미처리 JavaScript 오류는 0건이었다. |
| C4 · 경계와 교환 | 기본 배송지 수정이 다음 주문서에 반영됐다. 도서산간 운임은 6,000원으로 바뀌었다. 운영자가 재고를 0으로 설정하자 구매 버튼이 비활성화됐다. 브라우저 뒤로 가기, 배송 후 교환 신청과 교환 송장 반영까지 확인했다. |

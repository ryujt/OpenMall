## 상태 후보별 재현 지점

| 후보 | 진입 지점과 확인할 결과 |
| --- | --- |
| A01~A07 | 계정에서 이메일 가입·확인, 기본 배송지 변경, 선택 동의와 탈퇴를 진행한다. 비회원 코드의 목적·주문·연락처·유효시간 및 비밀번호 복구 링크 재사용을 확인한다. |
| C01~C04 | 상품 찾기에서 검색·옵션을 선택한다. 운영자가 가격·재고·판매 상태를 바꾼 뒤 장바구니에서 이전 조건, 재고 부족, 선택·수정·삭제를 확인한다. |
| O01~O07 | 주문서에서 우편번호와 권역, 배송 불가, 배송비, 쿠폰 최소 금액과 현재 견적을 확인한다. 거래 엔진에서 마지막 재고 경합, 여러 SKU 중 한 건 부족, 같은 제출 키 재전송을 검사한다. |
| O08~O09 | 주문 조건 확인의 ‘주문 접수 상황 선택’에서 회신 지연을 고른다. 같은 주문을 복구하거나 중단한 후 예약·쿠폰 해제를 확인한다. |
| P01~P07 | 결제 인증에서 승인·거절·창 닫기·원거래 불일치·승인 후 공급 불가를 선택한다. 확정 전 출고 차단, 기한이 지난 예약 해제, 보상 전액 취소를 운영 예외와 함께 확인한다. |
| D01~D05 | 운영 출고에서 송장 등록, 포장 검수, 인계, 배송완료를 구분한다. 고객은 수량 일부 중지, 배송 중 철회, 주문 당시 주소와 미수령 상담을 확인한다. |
| R01~R07 | 주문 상세에서 품목·잔여 수량·사유·발견일·비용을 지정하고 예상 환불을 확인한다. 운영자는 실제 도착 수량·검수·양품·귀책·회수비와 원거래를 대조한다. 교환은 재고 확보, 대체 송장, 배송완료 또는 구매자 환불 선택으로 이어진다. |
| M01~M04 | 운영 상품·재고에서 필수 고시, 게시, 수정, 실사 하한을 검증한다. 역할별 접근과 감사 기록, 재무 원거래 대사와 미해결 예외를 열 수 있다. |
| H01~H05 | 두 탭에서 계정 또는 견적을 변경한다. 로그인 전 선택 품목과 회원 장바구니, 회원/비회원 주문 소유권, 수량 검증, 제출 키 충돌과 쿠폰 중복 예약을 대조한다. |
| H06~H10 | 미확정 카드 거래, 탈퇴자의 증빙 사본, 같은 SKU 교환 제한, 선물 수취인의 조회 거절, 인계 후 주소 변경 상담을 확인한다. |
| H11~H13 | 회수 방문 실패·재방문·수거, 다른 SKU나 부족한 수량의 입고 조사, 교환품 품절 때 구매자의 환불 전환을 확인한다. |
| T01~T05 | 운영자 두 계정으로 상품 버전 충돌, 중복 SKU, 오래된 실사 수량, 다른 주문에 사용된 송장과 실물 미인계 보류를 확인한다. |
| T06~T10 | 검사 수량 중 일부만 판매 가능 재고에 복귀한다. 귀책 판정 충돌, 거래일·정산일·수수료, 실행 직전 권한 회수, 동일 신청에 연결된 여러 상담과 응답을 비교한다. |
| PG01~PG05 | ‘설계 검수’에서 유효하지 않은 발신·다른 거래와 정상 승인, 당일 승인/취소 재대사를 반복한다. 재무 역할은 PG 원거래·지급 명세와 내부 금액을 비교한다. |
| LG01~LG04 | 물류에서 미인계 증빙 대조, 재방문·실제 수거, 다른 운송장 확인, 공식 배송완료 정정과 증빙을 다룬다. |
| NT01~NT03 | 발송을 의뢰한 뒤 회신 유실/재조회/실패를 같은 발송 식별자에서 확인한다. 재발급 전 인증번호가 뒤늦게 도착해도 최신 발급만 유효하다. |
| WK01~WK04 | 예약 만료의 주문·재고·쿠폰 처리, 실제 입고일 기준 휴일 제외 기한, 탈퇴 기록 만료 정리, PG 환불 확정 후 중단된 후속 전달을 독립적으로 재개한다. |

## 교차 시나리오와 증거

| 실행서 | 재현 경로 | 대조 값 |
| --- | --- | --- |
| X01 | [거래 테스트](tests/commerce.test.js)의 두 구매자·재고 예약 경합 | 변경 전 견적 거절, 전 품목 확보 또는 전량 미확보, 중단 뒤 늦은 성공에도 추가 결제 0건 |
| X02 | 원출고 포장 후 일부 취소 또는 인계 후 철회 | 무료 운임·승인 18,000원 예시에서 먼저 중지한 1개 환불 9,000원, 나머지 인계 1개 |
| X03 | 판매자 귀책 반품, 실제 입고·검수 후 원거래 부분 취소 대사 | 최초 48,000원, 부분 환불 18,000원, 잔액 30,000원. 같은 통지 재수신에도 환불 한 건 |
| X04 | 동일 SKU 교환, 원품 완료 통지와 교환품 배송 통지를 다른 순서로 전달 | 원송장·회수·교환 송장 분리, 교환품 배송완료 때 종결, 품절 시 구매자 선택 |
| X05 | 하단 ‘설계 검수 → 부분 취소 순서와 원 단위 배분’ | 각 10,001원인 세 품목의 1,000원 할인 배분은 334/333/333원. 취소 순서가 바뀌어도 32,003원 전액 환불 |
| X06 | ‘설계 검수 → 백업 복원과 원거래 대조’에서 조회 불가·미인계·이미 인계를 각각 선택 | 외부 증빙 없으면 보류. 원승인 18,000원 한 건과 창고 인수표에 따라 1개 인계. 실제 백업·복구 시간 측정은 운영 인수 대상 |

실제 PG의 카드·간편결제 계약, 현금성 수단 도입 시의 구매안전서비스·현금영수증, 발송사 조회 보장, 공휴일 원천 데이터와 개인정보 보존 운영은 시험 환경에서 별도로 확정한다. 설계의 후속 확장 항목 및 실물 인계·지급은 이 브라우저 프로토타입의 동작 범위 밖이다.

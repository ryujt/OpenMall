# OpenMall 생활 편집숍

국내 실물 상품 직영몰의 구매자 화면과 운영 화면을 React로 구현했다. 장바구니에 담은 수량, 주문 시 예약한 수량, 창고가 인계한 수량을 구분하며 구매자와 운영자가 같은 주문번호로 거래를 이어간다. PG·택배사·문자·이메일은 브라우저 안에서 동작하는 모의 서비스다.

## 실행

Node.js 22.12 이상에서 이 폴더를 기준으로 실행한다.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소를 연다. `npm run build`로 정적 파일을 만들고 `npm run preview`로 배포 구성을 확인할 수 있다. 앱은 해시 경로를 사용해 정적 호스팅에서도 개별 주문 주소를 다시 열 수 있다.

## 처음 체험할 때

1. **상품 찾기 → 상세 → 장바구니**. 코튼 핸드타월의 세이지 옵션을 2개 담는다. 상세에서 소재·규격·제조국·관리법과 배송 포함 금액을 확인한다.
2. **주문서 → 회원 로그인 → 체험 회원 로그인**. 일반 지역 배송비와 2,000원 쿠폰을 적용해 25,000원을 확인한다. 제주 주소 예시를 고르면 28,000원이 된다. 배송지나 옵션 가격이 바뀌면 최종 조건을 다시 확인한다.
3. **결제 인증 → 인증창 닫기·응답 지연**. 새로고침한 뒤 같은 주문의 ‘결과 다시 확인’을 누른다. 승인이 확인되면 영수증과 주문 당시 계약내용을 열 수 있다.
4. **주문 상세 → 출고 전 취소 신청**. 타월 1개를 선택해 할인 배분 후 환불 견적 11,000원을 확인하고 접수한다. 남은 1개는 출고 대상이다.
5. **하단 운영 체험 → 물류 담당자**. 가상 2차 인증 후 남은 수량을 포장하고 원송장을 등록한다. 실물 인계와 배송완료를 각각 기록한다. 재무 담당자로 전환해 취소 요청·PG 결과를 대조하면 고객 화면의 확정 환불액과 잔액이 바뀐다.
6. **주문 상세 → 반품·교환 신청**. 배송된 수량을 선택한다. 상담·물류·재무 담당자는 회수 운송장, 실제 입고, 검수와 양품 수량을 기록하고 환불 또는 동일 SKU 교환품 출고를 이어간다. 주문 상세에서 원송장·회수·교환 송장을 구분해 볼 수 있다.

## 인증과 운영 체험

- **회원**은 직접 가입하거나 체험 계정을 사용한다. 초기 계정은 `seoyun@example.test`, 비밀번호는 `OpenMall2026!`이다. 가입·주소록·선택 동의·복구·탈퇴는 ‘계정’에서 진행한다. 배송지 변경은 이후 주문에 적용된다.
- **비회원**은 주문 전 주문자 연락처를 인증한다. 문자와 메일은 ‘가상 수신함’에서 확인한다. 수취인 연락처는 별도다. 기존 주문은 ‘비회원 주문 조회’에서 주문번호와 원주문 연락처로 새 코드를 받아 연다. 발급 코드는 3분, 조회 권한은 15분 동안 유효하다. 재발급은 이전 코드를 무효화한다.
- **운영자**는 상품·재고·물류·상담·재무·권한 관리자 중 역할을 고르고 화면에 표시되는 가상 2차 인증번호를 입력한다. 상품 편집과 재고 실사, 출고와 환불 등은 담당 권한별로 나뉜다. 권한 관리자는 열린 다른 탭의 담당자 권한도 회수할 수 있다.
- **예외 재현**은 주문 접수 지연, PG 응답 지연, 승인 불일치, 회수 방문 실패, 입고 수량 불일치, 원거래 대사 메뉴에서 진행한다. 운영 관리에서 업무 시각과 휴무일을 설정해 공급·환급기한을 점검할 수 있다. 하단 ‘설계 검수’는 고정된 별도 주문에서 1원 할인 배분, 중복 PG 통지, 일별 대사 중단과 백업 복구를 반복한다.

## 저장·초기화와 시험 가정

상품 세 종류와 타월 색상 두 가지로 시작한다. 주문·재고·계정은 같은 출처의 브라우저 저장소를 공유한다. 같은 브라우저 프로필의 탭에서 구매자와 운영자를 동시에 열 수 있다. 커밋 시 저장 버전을 확인하며 Web Locks를 지원하는 브라우저에서는 동시 쓰기를 직렬화한다. 조회 인증과 운영 담당자의 세션은 탭 단위다. 기존 프로토타입의 주문과 장바구니는 읽을 때 새 형식으로 변환한다.

‘운영 체험 → 체험 데이터 관리 → 체험 데이터 초기화’에서 확인하면 기본 상태로 돌아간다. 개인정보와 결제 정보에는 가상 값을 사용한다. 기본 운임은 일반 3,000원, 도서산간 6,000원이며 우편번호·마감·운임표는 검토용 정책이다. 영업일 계산에는 주말과 입력한 휴무일을 사용한다. 실서비스의 PG 거래 진위 확인, 권한 보안, 국내 휴일 데이터 연동, 외부 물류·발송, 백업 인프라와 부하 목표는 별도 인수 대상이다.

```sh
npm test
npx playwright install chromium
npm run test:browser
```

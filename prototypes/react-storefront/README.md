# OpenMall 생활 편집숍

React와 Vite로 만든 국내 쇼핑몰 프로토타입이다. 한 브라우저에서 구매자와 운영자의 역할을 바꿔 주문의 전 과정을 체험할 수 있다.

## 실행

Node.js 22.12 이상에서 이 폴더로 이동해 실행한다.

```sh
npm ci
npm run dev
```

터미널에 표시된 주소를 열면 생활 셀렉션이 나온다. 배포 파일은 `npm run build`로 생성하고 `npm run preview`로 열 수 있다.

## 체험 순서

1. 상품을 검색하거나 패브릭·키친·배스로 좁힌다. 사진의 하트를 누르면 상단의 ‘찜한 상품’에 저장된다.
2. 코튼 핸드타월 상세에서 장바구니에 담고 수량을 2개로 바꾼다. 일반 지역 배송비를 포함한 금액은 27,000원이다.
3. 주문하기에서 체험 회원을 선택하고 2,000원 쿠폰을 적용한다. 가상 결제를 완료하면 주문 상세에 25,000원이 표시된다. 비회원 체험은 주문번호와 입력한 연락처로 계정 화면에서 다시 조회할 수 있다.
4. 출고 전에는 주문 상세에서 취소를 신청한다. 하단 ‘운영 체험 → 고객상담·환불’에서 환불을 확정하면 재고가 복원되고 주문 상세에 결과가 반영된다.
5. 배송을 체험하려면 새 주문을 만든다. ‘운영 체험 → 출고 관리’에서 숫자 8~16자리의 예시 운송장을 입력하고 배송완료 처리한다. 주문 상세에서 반품 또는 교환을 신청한다.
6. ‘운영 체험 → 상품·재고’에서 가격과 재고를 바꾸면 상품 페이지에 반영된다. 회원 정보에서 저장한 기본 배송지는 이후 회원 주문에 적용된다.

## 저장과 초기화

가상 회원 한 명, 상품 세 종류와 빈 장바구니로 시작한다. 회원·배송지·주문·운영 상태는 같은 브라우저의 `localStorage`에 저장한다. 예시 연락처와 주소를 사용한다. ‘운영 체험 → 체험 데이터 관리 → 체험 데이터 초기화’에서 확인하면 처음 상태로 돌아간다.

## 체험 범위

[화면 설계](../../docs/design/2026-11-22/to-be/screen-layout.md)의 정상 구매 흐름을 기준으로 했다. 회원 로그인은 체험 계정 선택, 비회원 조회는 주문번호와 연락처 대조로 단순화했다. 쿠폰은 회원 주문마다 한 장을 선택하며 반품·교환·취소는 주문 전체 단위다. 운영 화면은 역할 전환용으로 공개한다. 실제 인증, 카드 승인, 환불 송금, 택배 조회, 부분 취소·비용 정산 및 여러 브라우저 간 동기화는 구현 범위 밖이다.

사진은 내장 이미지 생성 도구로 만든 2×2 정물 사진을 [네 장의 WebP](public/images/)로 분리했다. 생성 요청은 햇빛 아래 리넨과 머그, 접은 세이지·아이보리 타월, 샌드색 머그, 호박색 핸드워시 병을 글자 없는 생활 편집숍 사진으로 구성하는 것이었다. 글꼴·아이콘·사진을 포함한 화면 자산은 앱과 함께 제공한다.
